# Greenhill Library Website

A Library Website created using HTML, CSS XML, XLST and DTD. This was a group project, and was built as part of a Module at Middlesex University (Year 1).

## Files 

Library.html 
Books.xml
Books.xsl
books.dtd

## Purpose 

Promotion: The Library website was built to promote the Greenhill Library and provide users information about the company and what books are available. 

## What was built

- A HTML landing page for the user that provides navigation to other pages
- a books page that utilises XSLT to display XML data of books with DTD to validate XML structure
- An about us page that gives the user a brief about the Greenhill Library Company

## How to run

- Clone or download the reposistory.
- Open the project in Visual Studio Code.
- Install the Live Server Extension
- Right click Library.html and select 'open with live server' and the website will open on a web browser.
- Click the books tab to view the XML/XSLT book table.
